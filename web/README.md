# Cuaderno de campo · demostración local

La ruta `/` es un cuaderno de campo visual con datos enteramente inventados. No contiene clientes reales, documentos ni recomendaciones agronómicas; no consulta la API ni crea órdenes. `/backoffice` es una ruta distinta para iniciar sesión contra la API privada y administrar clientes, campos, lotes, cultivos, campañas, labores y recetas internas guardados en PostgreSQL local, y consultar la procedencia de los registros importados.

## Inicio local

En Windows, ejecute `C:\shortcuts\run-agro-operations-local.bat` (o busque **Agro Operations Local** en el menú Inicio); es el único acceso local. Ambos ejecutan `tools/start-local.ps1` de este repositorio, que levanta todo lo necesario: inicia Docker Desktop si no está en ejecución, abre en una ventana aparte la base PostgreSQL privada y la API protegida (`tools/start-backoffice-api.ps1`, que aplica solo las migraciones aditivas que falten), inicia la vista web y abre `http://127.0.0.1:3000/backoffice`. La demostración con datos inventados sigue en `/`. Requiere Docker, .NET, Node.js y pnpm (si el Explorador no encuentra Node.js o pnpm en `PATH`, usa la versión predeterminada de fnm y el pnpm de este usuario) e instala dependencias web solo si faltan. Mantenga abierta la consola y use **Ctrl+C** para detener el servidor web; la API se detiene con **Ctrl+C** en su propia ventana y los datos quedan en el volumen de Docker. Si la API o esta misma vista ya están en ejecución, el BAT las reutiliza sin iniciar otras instancias. Si el puerto 3000 pertenece a otro servicio o la identidad de la demostración no puede verificarse, el BAT rechaza la apertura; cierre ese servicio antes de reintentarlo. Ninguno inicia con Windows. Si el repositorio cambia de ubicación, actualice la ruta del archivo `.bat`.

Sin el acceso directo, desde `web/` ejecute `LOCAL_PREVIEW=1 NODE_ENV=development pnpm dev` (en PowerShell: `$env:LOCAL_PREVIEW='1'; $env:NODE_ENV='development'; pnpm dev`). El comando liga únicamente a `127.0.0.1`; fuera de modo desarrollo/local, el servidor de desarrollo rechaza el arranque y las rutas `/` y `/backoffice` responden como no encontradas. No desplegar este prototipo.

Para ver el usuario y la contraseña del administrador local de `/backoffice`, ejecute `tools/show-backoffice-login.ps1` solo en una consola interactiva; no redirija su salida a un archivo. Para iniciar solo la API, ejecute **en otra consola** `tools/start-backoffice-api.ps1`. La ruta web solo usa un proxy a `127.0.0.1:5081` en desarrollo; la API exige cookie y CSRF, incluso cuando el cuaderno de demostración sigue visible. El lanzador no importa datos reales.

Pruebas: `npm test`. Compilación: `npm run build`. La compilación no habilita la vista en producción.
